# Fake News Detection System

A machine learning-based web application that analyzes news headlines and article content to classify news using a trained text classification model.

The project combines **Machine Learning, NLP, Flask, HTML, CSS, and JavaScript** to provide a simple web interface for testing news articles.

---

## Features

- News headline and article content input
- Machine learning-based news classification
- NLP text vectorization
- Flask backend
- Responsive web interface
- Real-time word and character count
- Estimated reading time
- Example article for quick testing
- Clear input functionality
- Loading state during prediction
- Error handling
- Copy prediction result
- Responsive design for desktop and mobile

---

## How It Works

The system follows a simple workflow:

```text
User Input
    ↓
News Headline + Article Content
    ↓
Text Combination
    ↓
Saved NLP Vectorizer
    ↓
Trained Machine Learning Model
    ↓
Prediction
    ↓
Result Display
```

The headline and article content are combined and passed through the saved vectorizer. The transformed text is then provided to the trained machine learning model, which returns the predicted class.

## Installation
1. Clone the repository
git clone https://github.com/SaniaSalahuddin/NewsGuard-News-Classification.git

2. Open the project
cd fake-news-detection

3. Create a virtual environment
python -m venv venv

4. Activate the virtual environment
Windows
venv\Scripts\activate

macOS / Linux
source venv/bin/activate

5. Install dependencies
pip install flask scikit-learn

## Running the Application
Run the Flask application:
python app.py

The application will be available at:
http://127.0.0.1:5000/

Open the URL in your browser to use the application.
Using the Application
1. Enter a news headline.
2. Paste the article content.
3. Click Analyze Article.
4. The application sends the input to the Flask backend.
5. The trained model processes the text.
6. The predicted class is displayed in the result panel.
You can also use the Use Example button to quickly test the application.
API Endpoint
The application provides a prediction endpoint:
POST /predict

Request
{
    "title": "News headline",
    "text": "News article content..."
}

Response
{
    "prediction": "..."
}

If the input is missing:
{
    "error": "Please enter the text and title for analysis"
}

## Important Note
The prediction is generated by a machine learning model and should not be considered definitive verification of whether a news article is actually true or false.
The system is intended as a machine learning project demonstrating NLP text classification and model deployment through Flask.
