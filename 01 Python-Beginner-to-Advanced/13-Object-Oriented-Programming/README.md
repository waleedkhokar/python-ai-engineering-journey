## 📚 What I Learned

In this section, I studied and practiced the core concepts of **Object-Oriented Programming (OOP)** in Python.

OOP helps organize code using **classes and objects**, making applications easier to build, reuse, maintain, and extend.

### Core OOP Concepts

- Classes and Objects
- Attributes and Methods
- Constructors (`__init__`)
- Inheritance
- Parent and Child Classes
- Method Overriding
- Polymorphism
- Encapsulation
- Public, Protected, and Private Members
- `super()`
- Method Resolution Order (MRO)
- Abstract Classes
- Composition vs Inheritance
- Magic Methods and special object behavior
