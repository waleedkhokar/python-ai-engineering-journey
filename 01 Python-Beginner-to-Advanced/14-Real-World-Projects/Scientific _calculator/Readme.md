***Scientific Calculator***

A feature-rich calculator that works in three modes: Python GUI, Python Terminal, and Web Browser.

Screenshot

Screenshot 1 — Scientific Calculator

***Project Files***

File| Description
"scientific_calculator_gui.py"| Python GUI Calculator using Tkinter
"scientific_calculator.py"| Python Terminal Calculator
"index.html"| Web Calculator using HTML, CSS, and JavaScript

***Features***

- Basic Operations: Addition, subtraction, multiplication, division, and modulus.
- Trigonometric Functions: sin, cos, tan, and inverse functions.
- Logarithmic Functions: ln and log.
- Square Root: Calculate square roots.
- Power Functions: x² and xʸ.
- Factorial: n!
- Mathematical Constants: π and e.
- DEG / RAD Mode: Switch between degrees and radians.
- Memory Functions: MC, MR, M+, M−.
- Previous Answer (Ans): Reuse the previous result.
- Calculation History: Review previous calculations.
- Keyboard Support: Use keyboard shortcuts.
- Safe Expression Parser: No "eval()" usage.

Technologies Used

- Python 3
- Tkinter
- HTML5
- CSS3
- JavaScript

How to Run

Python GUI Calculator

Requirement: Python 3

python scientific_calculator_gui.py

Python Terminal Calculator

python scientific_calculator.py

- "help" — View available commands.
- "exit" — Close the calculator.

***Web Calculator***

Open "index.html" in your browser.

Installation: Not required for local use.

Keyboard Shortcuts

Key| Function
"0–9", "."| Enter numbers
"+ - * /"| Basic operations
"^"| Power
"!"| Factorial
"%"| Modulus
"Enter"| Calculate result
"Backspace"| Delete last character
"Esc"| Clear all input

Example Calculations

- "2 + 3 * 4" = 14
- "sin(30)" = 0.5 (DEG mode)
- "5!" = 120
- "sqrt(16)" = 4
- "2^10" = 1024
