# Python GUI Calculator

## Project Overview
A simple desktop calculator built with Python and Tkinter. It gives users a clean graphical window where they can click buttons to do everyday calculations, instead of typing commands in the terminal.

**Problem solved:** Makes basic arithmetic quick and easy through a friendly graphical interface, and shows how to build a GUI application in Python.

## Key Features
- Graphical user interface built with Tkinter
- Basic operations: addition, subtraction, multiplication, division
- Clickable number and operator buttons
- Clear button to reset the display
- Easy to read and beginner friendly code

## Technologies Used
- Python 3
- Tkinter (built into Python, no extra installation needed)

## Project Structure
```
python-gui-calculator/
├── README.md
└── calc.py
```

## Installation and Setup
1. Install Python 3 from [python.org](https://www.python.org/downloads/) if you don't have it.
2. Download or clone this project folder.
3. No extra libraries are needed, because Tkinter comes with Python.

## How to Run
Open a terminal in the project folder and run:
```
python calc.py
```
The calculator window will open.

## Example Output
A small calculator window opens with number buttons, operator buttons and a display at the top. Click the buttons to enter a calculation and see the result.
