# CyberSafe AI

CyberSafe AI is an AI-powered cybersecurity web application that helps users identify and understand common cyber threats. It provides intelligent analysis for suspicious emails, URLs, SMS messages, and passwords while also offering cybersecurity learning resources.

## Live Demo

https://cyber-safe-ai-indol.vercel.app/

## GitHub Repository

https://github.com/rukaiyaaaaa/CyberSafe-AI

## Features

- Email Investigation
- URL Investigation
- SMS Scam Detection
- Password Security Analysis
- AI Cyber Tutor
- Threat Reports
- Investigation History
- User Authentication with Supabase
- Secure Login & Email Verification

## Tech Stack

- React
- Vite
- Tailwind CSS
- Supabase
- OpenRouter AI API
- JavaScript

## How to Use

1. Open the live application.
2. Register using your email address.
3. Verify your email by clicking the verification link sent to your inbox.
4. Log in using your verified account.
5. Access the dashboard and use any of the cybersecurity tools.

## Installation

```bash
git clone https://github.com/rukaiyaaaaa/CyberSafe-AI.git
cd CyberSafe-AI
npm install
npm run dev
```

## Environment Variables

Create a `.env` file and add:

```env
VITE_SUPABASE_URL=YOUR_SUPABASE_URL
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
VITE_OPENROUTER_API_KEY=YOUR_OPENROUTER_API_KEY
```
