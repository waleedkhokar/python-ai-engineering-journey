COMPUTER NETWORKING QUICK REFERENCE

TCP AND UDP
TCP (Transmission Control Protocol) is connection-oriented. It establishes a connection using a three-way handshake: SYN, SYN-ACK, ACK. TCP provides ordered and reliable delivery using acknowledgements and retransmissions.
UDP (User Datagram Protocol) is connectionless and has lower overhead. It does not guarantee delivery, ordering, or retransmission. DNS queries, voice, video, and some real-time applications commonly use UDP.

DHCP
DHCP (Dynamic Host Configuration Protocol) automatically provides network configuration to clients. The common DORA sequence is Discover, Offer, Request, Acknowledge. DHCP commonly uses UDP ports 67 (server) and 68 (client).

DNS
DNS (Domain Name System) translates domain names into IP addresses. DNS commonly uses UDP port 53; TCP port 53 is also used for zone transfers and some large responses.

NAT AND PAT
NAT (Network Address Translation) translates IP addresses between networks. PAT (Port Address Translation), also called NAT overload, allows multiple private hosts to share a public IPv4 address using transport-layer port numbers.

VLAN
A VLAN (Virtual Local Area Network) logically separates Layer 2 broadcast domains on a switch. Access ports normally carry traffic for one VLAN. Trunk ports carry traffic for multiple VLANs using tagging, commonly IEEE 802.1Q (dot1q).

SUBNETTING
An IPv4 address contains 32 bits. A prefix such as /24 means 24 bits identify the network and 8 bits identify host addresses. A /24 subnet mask is 255.255.255.0. For a conventional subnet with more than two addresses, the first address is the network address and the last address is the broadcast address.

OSI MODEL
The seven OSI layers are Physical, Data Link, Network, Transport, Session, Presentation, and Application. Routers primarily operate at Layer 3. Traditional Ethernet switches primarily operate at Layer 2.

COMMON PORTS
FTP 20/21, SSH 22, Telnet 23, SMTP 25, DNS 53, DHCP 67/68, HTTP 80, POP3 110, NTP 123, IMAP 143, SNMP 161, HTTPS 443, RDP 3389.

CISCO IOS BASICS
enable enters privileged EXEC mode. configure terminal enters global configuration mode. interface g0/0 selects an interface. ip address assigns an IPv4 address and mask. no shutdown enables the interface. show ip interface brief displays interface status and addressing. show running-config displays the active configuration.
