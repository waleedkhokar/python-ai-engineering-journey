# The Problem

Many university students rely on grammar correction tools that only fix mistakes without explaining *why* those mistakes occur. As a result, students often submit improved assignments but never actually develop stronger writing skills.

LinguaLens AI was created to solve this problem by acting as an encouraging academic writing mentor rather than a text rewriting tool. Instead of replacing the student's work, it analyses their writing, identifies strengths and weaknesses, explains mistakes in simple language, and provides personalised suggestions that help students become independent academic writers.

The application is particularly useful for undergraduate students, postgraduate students, researchers, thesis writers, and anyone who wants to improve academic writing skills.

# AI Feature

The core feature of LinguaLens AI is its intelligent academic writing mentor powered by Google Gemini.

Unlike traditional grammar correction tools, LinguaLens does not simply rewrite the user's work. Instead, it analyses the writing and provides educational feedback designed to improve long-term writing ability.

The AI evaluates:

- Grammar
- Academic vocabulary
- Sentence structure
- Clarity
- Coherence
- Organisation
- Academic tone
- Style
- Critical thinking
- Overall writing quality

The AI then generates structured feedback explaining:

- what is working well
- what needs improvement
- why changes are necessary
- practical suggestions for revision

# AI Mentor Philosophy

LinguaLens AI follows one important educational principle:

> "Teach the writer instead of replacing the writer."

The AI behaves like a supportive university writing mentor by encouraging students to understand their mistakes and improve independently rather than depending on automatic rewriting.

# Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/LinguaLens-AI-Writing-Coach.git
```

Navigate into the project:

```bash
cd LinguaLens-AI-Writing-Coach
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```

---

# Environment Variables

Create a `.env.local` file and add the following variables:

```env
GEMINI_API_KEY=your_gemini_api_key

NEXT_PUBLIC_SUPABASE_URL=your_supabase_url

NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```

**Never commit API keys or secrets to GitHub.**
